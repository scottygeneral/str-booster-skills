# Free Airbnb Listing Copywriter for Claude

Turn Claude into an OTA copywriter that writes listings guests actually click: **titles, summaries, "The space" and neighborhood highlights** for Airbnb, Vrbo, Booking.com and your direct-booking site.

Built by **[David Anthony Scott](https://strbooster.com/?utm_source=github&utm_medium=readme&utm_campaign=ota-copywriter)**: Cornell-certified hospitality strategist, PriceLabs Certified Revenue Manager, and author of *Booked Solid*.

---

## What it does differently

- **The guest is the star, the property is the supporting actor.** Copy puts guests inside the stay instead of reading like a spec sheet.
- **Benefits lead, features support.** No comma-separated amenity dumps, no "stunning," "nestled" or "welcome to."
- **Fact-checks your listing.** It flags contradictions such as a bedroom count that doesn't match, WiFi speeds that disagree, or a walk time that's been rounded down. That alone can save you a bad review.
- **Platform-aware.** It respects Airbnb's 50-character title and 500-character summary limits, and adjusts tone for Vrbo, Booking.com and direct sites.
- **One clear recommendation.** You get a recommended title and two alternates with character counts, not a menu of ten.

## Install (2 minutes)

### Claude app (claude.ai, desktop, mobile)
1. Download **[ota-listing-copywriter.zip](dist/ota-listing-copywriter.zip)** (click it, then the download button).
2. In Claude, go to **Settings → Capabilities → Skills → Upload skill** and choose the zip.
3. Start a chat and ask.

### Claude Code
```bash
/plugin marketplace add scottygeneral/str-booster-skills
/plugin install str-booster@str-booster
```

## Use it

> Write my Airbnb listing. 3BR cottage, 5-minute walk to downtown Asheville, hot tub, fire pit, sleeps 8. Here's my Ideal Guest Avatar: [paste or upload]

Claude asks for anything essential that's missing, then delivers ready-to-paste blocks: the title (with alternates), the summary, the description and neighborhood highlights.

**Tip:** paste your current listing too. The skill will catch contradictions and claims that don't match.
